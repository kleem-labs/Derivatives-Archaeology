# The 50-Chamber Memory Palace

The palace is a retrieval instrument, not a substitute for the chapters. Walk it in order. In every chamber recall four things before opening the linked excavation: **pressure**, **failed shortcut**, **repair**, and **seal**. The seal is a physical image that should bring the mathematical responsibility back to mind.
